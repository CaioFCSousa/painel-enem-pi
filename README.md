# Painel ENEM 2025 — Piauí

Painel com o desempenho dos participantes do ENEM 2025 no Piauí, feito a partir dos microdados oficiais do INEP:
médias por área, redação, acerto por habilidade da Matriz de Referência, questões com menor acerto,
rede de ensino, municípios e a separação por Gerência Regional de Educação (GRE).

- Fonte dos dados: Microdados do ENEM 2025 — INEP (dados anonimizados, sem identificação de participantes).
- Divisão por GRE: lista básica de escolas estaduais da SEDUC-PI.
- Os botões "Baixar PDF" geram relatórios do estado inteiro ou de uma GRE.

Para atualizar os números, rode o `tratar_enem.py` com os microdados e substitua o `dados_enem_pi.js` deste repositório.
